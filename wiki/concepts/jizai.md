# 自在

定義の正本: [canon/glossary.md](../../canon/glossary.md#hs-c-0009)

<!-- HS-DEF-QUOTE:BEGIN id=HS-C-0009 revision=1 source=canon/glossary.md -->
> **定義**: 自を起点として、縁起の内で、自らの形成に介入しながら在ること（古訓「ワガマヽナリ」）。
<!-- HS-DEF-QUOTE:END -->

## 導入

自在は、「すべての条件から独立した意志があるか」という二択を離れ、条件の中でこの[鼎](kanae.md)が実際に何を変えうるかを問う概念である。生まれ、身体、言語、過去の経験、他鼎との関係、いま届いた刺激は、自分だけで選んだものではない。それでも、この鼎の[観](kan.md)を通らずに、この鼎の次の形成は起こらない。

したがって自在は、因果や縁起から脱出する能力ではない。縁起の一部である鼎が、自を起点として、受け取った現れにどう向き直り、次の形成へどう参加するかを表す。

## 要点

- 無条件の自由意志は置かない。介入そのものも縁起の内にある。
- 「自」は独立した実体ではなく、形成がそこから始まる起点である。
- 刺激の到来や最初の現れ・反射という**第一拍**は選べない。
- 第一拍の後には、注意を**向ける**、差し出された客鼎観を**受け取る**、自らの主鼎観を**差し出す**という介入がありうる。
- 介入は万能でも成功保証でもない。条件の一部として次の形成へ効くことが自在である。
- 「自由意志」は現行の体系語ではない。一般語・引用・思想比較・形成史で使う場合は、現行概念の自在と混同させない。

## 構造と働き

自在は、一回の選択点というより、形成の循環の中に現れる。

| 局面 | 何が起こるか | 自在との関係 |
|---|---|---|
| 縁と第一拍 | 刺激、身体反応、記憶の喚起、最初の感情や現れが生じる | ここまでを無条件に選べるとはしない |
| 向ける | 何へ注意を向け、何を見直すかが変わる | 観の指向への介入 |
| 受け取る | 他鼎から差し出されたものを客鼎観として迎える | 拒絶や服従ではなく、[吟味](ginmi.md)できる形で受を成立させる |
| 差し出す | 自らの主鼎観を、言・行為・物として表す | 他鼎との[事](koto.md)へ参加する |
| 次の形成 | 応答の結果が自他の次の縁になる | 介入も新たな条件となり、循環が続く |

この循環では、条件が先にあり、その条件に対する鼎の応答もまた次の条件を作る。波は海と無関係には立たないが、その場所に立った波の形は次の波の条件になる、という比喩で説明できる。比喩が示すのは独立性ではなく、依存しながら効くことである。

自在が現し界で出来事になるには、観の行が體を通り、[源則](gensoku.md)に律される物・事として現れなければならない。自在は「心が物理条件を無視して現実を作る」という主張ではない。

## 他概念との差

| 似て見える語 | 違い |
|---|---|
| 無条件の自由意志 | 条件や因果から独立した選択主体を想定しうる。自在はそれを否定し、縁起の内で形成経路に効くことを扱う |
| 自由 | 日常語・政治語・思想比較の語として使用できるが、本体系の中核語ではない。自在を「好き勝手」と同一視しない |
| 選択 | 選択は自在が現れる一場面である。注意を向ける、受け取る、差し出すなど、明示的な二択以前の介入も含む |
| 自己制御 | 抑制や管理だけを指さない。受け取るために開くことや、他鼎へ差し出すことも自在に含まれる |
| 決定論 | 自在は宇宙が決定論的か非決定論的かを確定しない。偶然があるだけでも自在にはならず、条件の中で鼎の形成が効くことを問題にする |
| 現代語の「わがまま」 | 定義中の古訓「ワガマヽナリ」は命名の来歴であり、他者を無視する身勝手さを肯定する語ではない |

## 具体例

### 強い言葉を受けたとき

他鼎から強い言葉が届き、驚きや怒りが立ち上がる。その最初の反応まで「選ばなかった自分の失敗」とはしない。すぐに同じ強さで返す代わりに、何が差し出されたのかへ注意を向け、客鼎観として受け取り、吟味してから差分を返す。この向け直しが次の事を変える。必ず関係が良くなるわけではないが、反応だけで形成が閉じることを避けられる。

### 読み直して考えを変える

一度は退けた文章を、別の経験の後に読み直す。同じ文字でも、現在の鼎の形が違えば別の客鼎観が成立しうる。何を読み直すか、どこへ注意を向けるか、理解した差分をどう返すかに介入することは、過去を消さずに未来の形成を変える自在の例である。

### 制約のある制作

使える時間、身体、道具、既にある言葉は選び切れない。それでも、どの問いを保ち、どの表現を吟味し、何を作品として差し出すかによって次の形成は変わる。制約があることは、制作する鼎が経路上で効いていないことを意味しない。

## よくある誤読

**自在なら何でも思い通りにできますか。** できない。自在は万能性ではなく、条件の内で形成に介入することを指す。結果には他鼎、體、源則、偶然を含む多くの縁が関わる。

**第一拍を選べないなら、責任はありませんか。** 定義から直ちに責任の有無や配分は決まらない。少なくとも、最初の反応と、その後にどう引き受けて応答するかを分けて考える枠組みは与える。法的・道徳的責任論の全体は別途吟味を要する。

**すべて縁起なら、私が何をしても同じですか。** 同じではない。介入も縁の一つとして次の形成条件になる。「独立していない」と「効いていない」を同一視しない。

**自在は精神が物理法則を超える力ですか。** 違う。観の行が現し界に現れるには體を通り、源則に律される。自在はこの条件を破る例外ではない。

**自由意志を自在と言い換えただけですか。** 違う。旧語を同義語へ機械置換したのではなく、問いを「無条件に自由か」から「形成経路上でこの鼎が効くか」へ組み替えた。自在は、自由意志とは別に定義された後継概念である。

## 形成史・版

- v0.1.1では「自由意志」を**形成への参加能力**と定義し、「自由意志はないが、未来は変えられる」と説明した。
- v0.2.0で、無条件の自由意志はないことを縁起から明示し、形成への参加能力を自在の説明へ移した。
- この変更は単なる改名ではない。「自由意志」を旧概念として退け、「自在」を別の後継概念として定義した。
- 旧語「自由意志」は、本体系の現行概念として無注記では用いない。一般語、引用、他思想との比較、形成史で使う場合は、旧概念であり後継が自在であることを明示する。
- 旧記述の中身を捨てたのではない。「形成への参加能力」は、縁起内の介入として限定を明確にしたうえで自在へ継承された。

旧概念の履歴は[自由意志（比較語・履歴）](../../canon/glossary.md#hs-c-0010)、現行の定義は[自在](../../canon/glossary.md#hs-c-0009)を参照する。

## 関係型付き関連概念

| 関係型 | 概念 | 関係の説明 |
|---|---|---|
| 起点となる | [鼎](kanae.md) | 自在は、独立実体ではない鼎の「自」を起点として生じる |
| 介入する | [観](kan.md) | 向ける・受け取る・差し出すことを通じて形成経路へ関わる |
| 受け取る | [客鼎観](kyakuteikan.md) | 他鼎から差し出されたものを、拒絶も服従もせず受として成立させる |
| 差し出す | [主鼎観](shuteikan.md) | 自らの位置から形成した観を、言・行為・物として他鼎へ提供する |
| 吟味する | [吟味](ginmi.md) | 受け取った客鼎観を扱い、返す差分を形成する具体的な介入になる |
| 次の縁を作る | [事](koto.md) | 介入が出来事として現れ、自他の次の形成条件になる |
| 制約する | [源則](gensoku.md) | 現し界での介入は源則の外へ出ず、體と物・事を通して現れる |

## 出典・確度

- **【定義】** 自在と三つの動詞の正本は[用語集](../../canon/glossary.md#hs-c-0009)にある。
- **【系】** 無条件の自由意志から形成経路への問いの置換は、[原理と定理](../../canon/principles.md)の「系三（自在と介入）」を正とする。
- **形成史**：自由意志の退役と自在との後継関係は[用語集の履歴項目](../../canon/glossary.md#hs-c-0010)に記録されている。本ページは旧概念を現行定義として復活させない。
- **【解釈】** 強い言葉、読み直し、制作の例は定義を日常場面へ展開したものであり、介入の効果や成功を保証しない。
- **【検証課題】** 自在の程度をどう比較・測定するか、訓練可能性をどう実証するか、責任論とどう接続するかは本ページで確定しない。
