# 然

定義の正本: [用語集](../../canon/glossary.md)／[第十二原理](../../canon/principles.md)

> **定義**: 燃えていること。燃焼そのもの。情や出来事を糧として燃え、鼎の生を動かし続ける働き。

然は、[鼎](kanae.md)を内側から動かし続ける燃焼の働きである。固定した魂や、単独の感情の名ではない。燃える働き、燃やされる糧、それを守る[主](aruji.md)、保つ[體](tai.md)を区別することで、鼎の生を関係の中で捉える。

## 問いから読む

### 然は、生命力や感情の別名か

どちらか一つの別名ではない。喜怒哀懼愛悪欲などの情は然の糧になりうるが、然そのものではない。食べる・眠る・休む・遊ぶといった身体的充足や、他鼎から受けた観・言・物・出来事も糧になる。

### 然は、どこから糧を得るのか

正本は二経路を置く。一つは體による充足という自給、もう一つは他鼎との授受による灯し合いである。然は他者だけに依存するのでも、完全に自給できるのでもない。まろうどは灯しにも消しにも来るため、受けたものを吟味する必要がある。

### 自然・偶然・依然・必然は、然とどう関係するか

正本は然の四様式として、自然（自ら）、偶然（出会いにより）、依然（依りて承け継いだまま）、必然（源則により）を区別する。これは四種類の物質や世界を立てる分類ではなく、然り方を四つの関係から読む体系内の区別である。

### 然と灯と光はどう違うのか

然は燃焼そのもの、灯は然が外へ働きうる形として現れたもの、光は灯を掲げ、その輝きが届くことである。内から外へ同じものがそのまま移動するというより、燃える働きが、他鼎へ届きうる現れを得る三段として区別される。

## 構造と働き

1. 體が身体的充足を通して然を保つ。
2. 主が、何を受け何を退けるかを吟味しながら然を守る。
3. 情・出来事・他鼎からの観などが糧として燃やされる。
4. 然が外へ働きうる形を取ると灯となり、他鼎へ届けば新たな形成を起こしうる。

この列は時間順の機械的工程を定義するものではなく、相互に関係する働きを読み分けた説明である。

## 近接語との境界

| 語 | 境界 |
|---|---|
| 糧 | 然が燃やすもの。然そのものではない |
| 灯 | 然が外へ働きうる形として現れたもの |
| 光 | 灯を掲げ、その輝きが届くこと |
| [主](aruji.md) | 然を守る働き |
| [體](tai.md) | 然が宿り、然を保つ全体 |
| 魂 | 本体系の原始語ではない。「魂と呼ばれてきたもの」は鼎に刻まれた則と然へ分解する【解釈】 |

## 出典・確度

- **【定義】** 然、然の四様式、糧、灯、光は[用語集](../../canon/glossary.md)と[原理と定理](../../canon/principles.md)を正とする。
- **【定理】** 糧の二経路と灯し合いは原理と定理に置かれる。
- **【象徴的読解】** 然を燃の初文として祭儀の火と読むこと、自然・偶然・依然・必然の字義との符合は定義を証明しない。
- **【検証課題】** 然や意識がどの存在に、いつ宿るかの一般判定は行わない。
