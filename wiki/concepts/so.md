# 想

定義の正本: [第二原理](../../canon/principles.md)／[用語集](../../canon/glossary.md)

> 観は**受・想・行・識**の四位相を持つ——受（受け取る）・想（切り取る）・行（向かう）・識（識る）。

想は、[観](kan.md)が「切り取る」位相である。日常語の空想だけに限定せず、受けたものを、その鼎にとっての一つのまとまり——かたち——として切り取る側を指す。ただし、かたちがどう結ばれるかについて、正本は独立した認知機構を定義していない。

## 問いから読む

### 想は、頭の中で映像を思い浮かべることか

それだけではない。正本が確定するのは「切り取る」という位相である。視覚像を思い浮かべることは一例になりうるが、言葉の意味を結ぶことや、音を一つのまとまりとして切り取ることを排除する定義ではない。【解釈】ただし、これらの例から心理学上の普遍的機構を導出しない。

### 想が物を作るのか

[物](mono.md)は、観が変化の流れから切り取った固定の現れである。【解釈】流れから一つのまとまりを切り取る想の位相と、物の定義——観による切り取り——は直結して読める。しかし、想だけが単独で物を生成する、または想像すれば外界の物質が生まれる、とは定義しない。

### 名前を付けることは想なのか

【解釈】命名は、現れを一つのまとまりとして結び、繰り返し指し示せるようにするため、想から読むことができる。しかし「想＝命名」という定義は正本にない。言語を持たない受や形成まで命名へ還元しない。

### 想は受の後、行の前に必ず起こるのか

四位相の列挙は、固定された時系列を定義していない。何を受けるかが想の形に関わり、行の結果が新たな想を結び、識ったことが以前のかたちを組み替える可能性がある。【解釈】四位相は、一つの形成を異なる働きから読む区別として扱う。

## 構造と働き

- **受との関係**: 受けたものが、受け手の鼎において一つのまとまりとして切り取られる。
- **物との関係**: 【解釈】変化の流れから固定した現れを切り取ることを、想の側から読むことができる。
- **行との関係**: 結ばれたかたちは、次の形成へ向かう行に関わる。
- **識との関係**: 切り取ることと、それを識ることは四位相として区別されるが、独立した二つの実体ではない。

## 近接語との境界

| 語 | 境界 |
|---|---|
| 想像 | 現前しない像を思い描く日常語。想の可能な一例だが、定義全体ではない |
| [物](mono.md) | 観が流れから切り取った固定の現れ。想との接続は【解釈】として示す |
| 形 | 現れの側の語。想は、かたちを切り取る観の位相 |
| 型 | 物を縛る則の側の語。想の別名ではない |
| 命名 | 名を与える行為。想から読めるが、想そのものと同義ではない |

## 出典・確度

- **【定義】** 想は「切り取る」という観の位相である。[第二原理](../../canon/principles.md)を正とする。
- **【解釈】** 物化・命名・像形成との接続は、正本の語を展開した読みであり、想の独立定義として固定しない。
- **【解釈】** 般若心経の想蘊との対応は体系を証明するものではない。
- **【検証課題】** 四位相の相互関係、時間順、心理学・神経科学上の過程との対応は未決である。
