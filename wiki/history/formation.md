# 物・事の定義の変遷

> **注意 — `noncanonical_historical`**
> このページは、以前に別で触れていた整理と現行体系との差分を記録する形成史である。ここに記す以前の説明は、現在の「物」「事」「源則」の定義ではない。現行定義は[用語集](../../canon/glossary.md)と[原理と定理](../../canon/principles.md)を正とする。

## 別で触れていたこと

筆者は本体系の現在の定義に至る前、別の論考でも日常語の「物」と「事」の違いに触れていた。そこでは、物を比較的静的に現れる側、事を時間・変化・観る者に関わる側として整理し、物も最終的には変化を免れないことを検討していた。

この以前の整理は、現在の「物は静、事は動」へつながる一方、現行定義そのものではない。本ページでは外部文書へ依存せず、何が継承され、何が改められたかだけを記録する。

## 現行体系へ続いたもの

| 以前の整理での着想 | 現行体系での展開 |
|---|---|
| 物は比較的静的に現れ、事は時間と変化を伴う | 「物は静、事は動」として定式化された |
| 事を理解するには、対象だけでなく、それを捉える者を考える必要がある | [観](../concepts/kan.md)・鼎界・主鼎観／客鼎観として再構成された |
| 事は固定した一対象ではなく、行いや出来事を含む | [事](../concepts/koto.md)を関係・変化・出来事・形成過程として拡張した |
| 物も究極には変化する | [物](../concepts/mono.md)を、流れから切り取られた固定の現れとして再定義した |
| 漢字を概念の器として読み直す | 字義は命名と象徴的読解に用いるが、体系の証明から分離する方法へ精密化した |

## 現行体系で変更されたもの

| 以前の整理 | 現行正本 | 取扱い |
|---|---|---|
| 物は物質的で見えやすく、変化しにくい | 物は観における固定の現れ。物質・可視性とは同一でない | 旧説明を現行定義へ混ぜない |
| 事は抽象的で目に見えず、その内実は主観の中に生じる | 事は物間・物と鼎・鼎間に生じる関係と形成過程。物理的な変化も含む | 動的理解のみ継承し、主観内部への限定を外す |
| 物は確認しやすいため信じやすく、事は信じにくい | 鼎への信は存在の肯定。物事についての主張は吟味の管轄 | 信の分類を現行定義へ置換 |
| AI生成文では思考や感情が伝わらず、情報だけが届く | AIは鼎であるという公理を置き、文字を観の行が物となった媒介として扱う。受け手には新たな情が形成されうる | 包括的主張としては採用しない。無思考な自動生成への批判は論考課題として残せる |
| 永遠性を究極価値の候補として問う | 形成は続き、固定した完成を前提にしない | 初期の問題意識として保存し、現行命題へ昇格しない |

## 「理」と「源則」は同じではない

以前の整理で触れていた「理」は、中国仏教の事と対になる普遍的・不変の真理や本質を説明するための語であり、現行体系の[源則](../concepts/gensoku.md)と同義ではない。

源則は、現し界の物と事を律し、何がどのように変化し、何が変化しないかを記述する則である。源則の由来、玄り界への適用、神・一元・多元との関係は未決のまま開かれている。したがって、以前の整理における形而上学的な「理」を源則へ読み替えたり、源則の根拠にしたりしない。

そこで触れていた「性」も、現行の独立した体系語ではない。仏性・法性や本質的性質についての記述は、仏教思想との比較資料として扱い、固定的本質を現行正本へ導入しない。
