# その他の思想との吟味

ここでの比較は、本体系における**吟味**の実践である。過去の思想を批判して退けるのでも、権威として飲み込むのでもない。相手の問い・文脈・貢献をまず受け取り、重なる点・異なる点・未決点を識り、本体系から見えた差分を返す。差異は優劣や克服の宣言ではなく、吟味の結果である。

## 中心比較

- [カント](kant.md) — 現象／物自体と、現し界／玄り界の非同一性
- [ヘーゲル](hegel.md) — 止揚における差異の保存と、鼎立・鼎合の非融合性
- [ユクスキュルの環世界](uexkull.md) — Umwelt・機能環と、一鼎ごとの鼎界・授受
- [中立一元論](neutral-monism.md) — 心／物の二元論を避けつつ、中立的な基礎素材を置かない差
