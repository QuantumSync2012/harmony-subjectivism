## 本体系の性格

**本体系は「主観論」ではなく「形成論」である。**

中心命題は「人は世界を形成する」ではない。**「世界を形成することによって、鼎（Kanae）も形成される」**であり、さらに**「鼎（Kanae）同士は互いを形成し合う」**である。世界は完成したものではなく、形成され続ける。ゆえに調和とは完成状態ではなく、**形成の様式**である。v0.2.0で確定した動力学を継承し、v1.0.0はその意味を概念別・質問別にたどれる形へ展開した——**調和は保証されない。授受と信と吟味によって生成する。**

**本体系は、漢字の字源から演繹された思想ではない。**既存の日本語の概念語には、本体系が避けようとする主体／客体、心／物、共有世界などの前提がすでに埋め込まれており、そのままでは必要な概念を表現できなかった。そこで概念上の必要を先に定め、漢字の古い意味・字形・派生字・語系・声系・熟語・用例を遡りながら語を選び直し、体系内で独自に定義した。その結果、甲骨文字等の古層と概念構造がしばしば響き合ったが、**この符合は体系の根拠ではなく、命名と象徴的読解の豊かさである**（方法の詳細は[用語集](canon/glossary.md)の「字義・派生の照合方法」）。

自己規定はこうである。**既存の概念語では表現できなかった問題を、独自の原初語彙と導出によって構成した、新しい形成論である。**その哲学史上の固有性は、近接思想との本査読によってさらに明確にする。

## 語義と定義の三層契約（最重要の前提）

**体系内概念としての意味は正本の定義が与え、辞書や字源から自動的には演繹しない。**ただし、語の選択と採否は勝手な命名ではない。辞書的・歴史的な字義と用例を資料別に確かめ、**①字そのものの意味、②その意味を踏まえた採用・不採用の理由、③体系内での用法**を分けて示す。哲学史上の既存概念との一致や差異も、比較章で出典の範囲を明らかにして扱う。

他思想との比較も、本体系のいう**吟味**として行う。過去の思想を退け、採点し、克服を宣言するためではない。それぞれの問い・文脈・貢献をまず受け取り、重なる点・異なる点・未決点を分け、本体系から見えた差分を返す。差異は優劣の宣言ではなく、吟味の結果である。

字源の確認は白川静『字通』を主たる出発点とし、『常用字解』『字統』、香港中文大学「漢語多功能字庫」等の公開学術データベース、先秦両漢の古典用例（中國哲學書電子化計劃）を資料別に照合する。資料間で説が分かれる場合は差異を併記する。白川説を絶対視せず、一学説として扱う。字源との一致は示してよいが、根拠として使ってはならない。字源・経典・科学との響き合いはすべて【象徴的読解】であり、体系の根拠は定義・公理・導出のみである。

## 表記規則（全文書共通）

- 鼎（Kanae）・観（Kan）・物（Mono）・事（Koto）は、定義・初出時に必ず漢字＋ローマ字を併記する
- 鼎の読み：単独では **kanae**、熟語内では **tei**（鼎談・鼎立と同じ音便）
- 鼎界（Teikai）は、**現し界（うつしかい）**と**玄り界（かくりかい）**に分かたれる。これが正式名称であり、初出時は必ずルビ付きの正式名称で宣言する。以後は略記**「現界」「玄界」**を用いてよい。略記を用いる文書は、冒頭で略記宣言を行う
- 正式語と略記：**主鼎観（Shuteikan）／以下、主観**・**客鼎観（Kyakuteikan）／以下、客観**と冒頭で宣言し、以後の「主観」「客観」はすべて略記として読む。主鼎観のあるじ・客鼎観のまろうどの読み分けも初出で示す
- 観の提供・観の受領に固有の語は作らない。「観（Kan）を差し出す」「観（Kan）の提供」という句で表す（分かりづらい語を増やさない方針）
- 確度ラベル：全主張に【定義】【公理】【定理】【系】【解釈】【象徴的読解】【字源】【無定義・管轄外】【検証課題】【地平】のいずれかを付す。未決を閉じない
- 字源との符合は【象徴的読解】として示す。一致は示してよいが、根拠として使ってはならない
- 英語版：Kanae / Kan / Mono / Koto / Shuteikan / Kyakuteikan は翻訳せず、初出時に定義を添える。英語略記は Self-Kan / Other-Kan。体系名は **Harmonious Subjectivism** に統一
